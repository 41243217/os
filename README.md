# os

GitHub Pages 刷題系統範例：

- `index.html`：主頁與學習統計
- `quiz.html`：開始測驗
- `review.html`：錯題回顧
- `study.html`：閱讀記憶
- `page.html`：最新題庫總覽

## 使用方式

1. 將專案部署到 GitHub Pages。
2. 進入 `index.html` 開始使用。
3. 題庫資料使用 `CH5.json`、`CH6.json`、`CH8.json`、`CH9.json`。
4. 測驗統計與錯題資料儲存在 `localStorage`（`quizStats`、`wrongQuestions`、`quizSettings`）。
